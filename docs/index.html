What it does

Audit score

Every public repo graded out of 100, worst first.

Leak scan

Secrets, personal data, junk files and terms you must never publish.

One README standard

Same structure everywhere, linted for broken links and filler words.

Smart renames

Consistent kebab-case names, with warnings for repos that have live URLs.

Profile README

A clean intro, skills and toolbox generated from a small JSON file.

Safe by design

Backups first. No deletes or force-pushes without your approval.
